## คำถามที่ HNW ถามบ่อยที่สุด

> ฟีน วงเงิน ฿100 ล้าน/ปี มันเยอะเกินไปหรือเปล่า?

คำตอบสั้นๆ: <strong>ไม่ เยอะแบบไม่จริงจังแล้ว เพราะคุณคือ HNW</strong>

แต่ขอเล่าวิธีคิดให้ฟัง — แล้วคุณตัดสินใจเอง

## ตารางค่ารักษาเคสรุนแรงในไทย (ปี 2569)

ข้อมูลจากเครือ BDMS / โรงพยาบาลเอกชนระดับ 5 ดาว — ตัวเลขโดยประมาณ:

| เคส | ระยะเวลา | ค่ารักษาทั้งหมด |
|---|---|---|
| ผ่าตัดบายพาสหัวใจ + ICU + ฟื้นฟู | 2–4 สัปดาห์ | ฿1.5–4 ล้าน |
| มะเร็งระยะ 2–3 + คีโม + ฉายแสง | 12 เดือน | ฿2.5–5 ล้าน |
| มะเร็งระยะ 4 + immunotherapy | 18–24 เดือน | ฿4–10 ล้าน |
| มะเร็งระยะลุกลาม + targeted therapy + cellular therapy | 24+ เดือน | ฿8–25 ล้าน |
| โรคหลอดเลือดสมอง + ICU 3 เดือน + ฟื้นฟู 1 ปี | 12–18 เดือน | ฿3–7 ล้าน |
| ปลูกถ่ายไต + กดภูมิคุ้มกันต่อเนื่อง | ตลอดชีวิต | ฿5–12 ล้าน + รายปี ฿800K |
| Sepsis + multi-organ failure + ECMO | 4–8 สัปดาห์ | ฿4–12 ล้าน |
| รักษาในต่างประเทศ (Mayo Clinic, Cleveland Clinic) | 3–6 เดือน | ฿15–40 ล้าน |

> ตัวเลขเป็นการประมาณจากข้อมูลสาธารณะ ค่าจริงต่างกันตามสถานพยาบาลและความรุนแรง

## กรอบ "Stress Test"

วิธีคิดของฟีน — ทำ stress test:

**คำถาม:** ถ้าฉันเจอเคสร้ายที่สุดที่อาจเกิดได้ในชีวิต — ครอบครัวยังอยู่ได้ไหม?

**ตัวอย่าง:**
- HNW อายุ 50 ปี ทรัพย์สินสุทธิ ฿200 ล้าน
- ภรรยาเป็น Stage 4 ovarian cancer ใช้ targeted therapy + experimental + รักษาที่สิงคโปร์
- ค่ารักษา 3 ปี = ฿18 ล้าน
- ค่าผู้ดูแล + ค่าเดินทางครอบครัว 3 ปี = ฿3 ล้าน
- รายได้ที่ขาดหายของผู้ป่วย 3 ปี = ฿9 ล้าน

**รวม cost ที่ครอบครัวต้องรับมือ:** ~฿30 ล้าน ในระยะ 3 ปี

ถ้าวงเงินประกันคุณ ฿20 ล้าน/ปี — คุณยังต้องจ่ายเอง ฿10 ล้านขึ้นไป
ถ้าวงเงินประกันคุณ ฿100 ล้าน/ปี — ประกันรับเต็ม ครอบครัวไม่ต้องเสียทรัพย์สินเพื่อรักษา

## กฎ 3 ขั้นของฟีน

### ขั้นต่ำ (Premium baseline)
ทรัพย์สินสุทธิ ฿20–50 ล้าน
**แนะนำ:** ฿20–30 ล้าน/ปี (Allianz First Class Ultra Platinum 80MB หรือ ดับเบิล แคร์ระดับสูง)

### มาตรฐาน HNW (HNW standard)
ทรัพย์สินสุทธิ ฿50–200 ล้าน
**แนะนำ:** ฿60–80 ล้าน/ปี (First Class Ultra @BDMS Platinum)

### HNW เต็มรูปแบบ (Full HNW)
ทรัพย์สินสุทธิ ฿200 ล้านขึ้นไป
**แนะนำ:** ฿100–120 ล้าน/ปี (Beyond Platinum 120MB) + Worldwide rider

## ทำไมไม่ควร "ประหยัด" ในชั้นนี้

เบี้ยประกันสุขภาพระดับ ฿100K–300K/ปี มัก <em>น้อยกว่า 0.1%</em> ของทรัพย์สินสุทธิของ HNW

แต่ความเสียหายที่ป้องกันได้ของวงเงินที่ต่ำเกินไป สามารถถึง <em>5–15%</em> ของทรัพย์สินสุทธิ
ในเคสที่รุนแรง

**สมการ:** เพิ่มเบี้ย ฿50K/ปี เพื่อเพิ่มวงเงินจาก ฿30M เป็น ฿100M = เพิ่ม peace of mind ที่
"ครอบครัวไม่ต้องเลือกระหว่างการรักษากับการรักษาทรัพย์สิน"
