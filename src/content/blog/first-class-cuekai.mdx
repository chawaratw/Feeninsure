## สรุปสั้น

**First Class Ultra** คือชุดประกันสุขภาพระดับสูงสุดของ Allianz Ayudhya
ออกแบบมาเพื่อกลุ่ม Premium และ HNW ที่ต้องการ:

1. **วงเงินคุ้มครองสูงสุด** ฿80–120 ล้านบาทต่อปี
2. **ไม่มี Co-payment** ในระดับ Beyond Platinum
3. **ต่ออายุได้ถึงอายุ 99 ปี** — แผนระยะยาวจริง

แตกต่างจากประกันสุขภาพทั่วไปตรงที่ "ระดับการคุ้มครอง" และ "ความยืดหยุ่นของเครือโรงพยาบาล"

## แผน First Class Ultra มี 4 ระดับ

1. **Standard** — เริ่มต้น เหมาะกับวัยทำงานทั่วไป
2. **Gold** — ขยายวงเงินและ benefits
3. **Platinum** — เริ่มเข้ากลุ่ม HNW (~฿80M/ปี)
4. **Beyond Platinum** — สูงสุด (~฿100–120M/ปี)

ฟีนแนะนำให้เลือกระดับตามความถี่ในการใช้บริการโรงพยาบาลเอกชน ไม่ใช่ตามเบี้ยที่จ่ายไหว

## ทำไม HNW ถึงต้องการแผนระดับนี้

ค่ารักษาในกรณีรุนแรงในไทย:
- **โรคมะเร็งระยะลุกลาม + การฉายแสง + คีโม** = ฿3–8 ล้าน
- **ผ่าตัดหัวใจเปิด + ICU + ฟื้นฟู** = ฿1.5–4 ล้าน
- **อุบัติเหตุที่ต้องใช้ ICU ยาว** = ฿500K–2M

แผนระดับ ฿20–30M/ปี ของหลายเจ้าจะเริ่ม "ปริ่ม" ในกรณีรุนแรงระยะยาว
First Class Ultra ทำหน้าที่ "buffer" สำหรับเคสที่ไม่คาดคิด

## ความต่างจาก @BDMS

ดู [เปรียบเทียบ First Class Ultra @BDMS vs Ultra](/blog/first-class-ultra-bdms-vs-ultra) — สรุปสั้น:

- **Ultra**: รับทุกโรงพยาบาล — ยืดหยุ่นกว่า แต่เบี้ยสูงกว่าในระดับวงเงินเดียวกัน
